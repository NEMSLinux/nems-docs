NEMS Linux 1.8 Changelogs (2026-Present)
========================================

NEMS 1.8 is a future release currently under heavy development.

**Key Development Features and Goals:**

-  **Firewall** - NEMS Linux was originally set to include `ConfigServer Security &
   Firewall (csf) with Login Failure Daemon (lfd)`_. However, that project
   has been abandoned. A different firewall may be implemented. Internal LAN IP
   addresses are whitelisted by default, but if a user tries to access
   your NEMS server from outside the LAN (ie., if you have your NEMS
   server accessible on the Internet) they will get locked out if they
   try an incorrect password too many times.
-  Add IPMI (freeipmi) if not added already.
-  Begin work on smart home assistant integration: NEMS Skill for Alexa
   and Google Assistant.

July 20-25, 2026 - NEMS Linux 1.8 is the primary focus of the 3rd annual NEMS Developer Lockdown.
